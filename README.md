# 🚀 Autonomous Simulation Platform

An intelligent AI-powered platform for creating and running physics simulations through natural language.

## 🌟 Features

- **Natural Language Interface**: Describe any simulation and watch it come to life
- **5 AI Agents**: Architect, SceneGraph, Physics, Validator, and Optimization agents
- **Real Physics Engine**: PyTorch-based physics with numerical integration
- **Interactive Web UI**: Chat-based interface powered by Gradio
- **Isaac Lab Integration**: NVIDIA Isaac Lab 0.47.1 + Isaac Sim 5.0.0

## 🚀 Quick Start

```bash
# Launch web interface
source venv311/bin/activate
python physics_ui.py

# Open browser to http://localhost:7860
```
